# EasyBook Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build EasyBook, a multi-restaurant table reservation app with conflict-safe booking, a refundable ₹25-per-person deposit, and an owner dashboard.

**Architecture:** Express + Mongoose REST API in MVC layout. Business rules live in pure, injectable-`now` service functions. Double-booking is prevented by a MongoDB partial unique index on `(table, date, slotStart)` for active statuses. Payments go through a gateway adapter (Razorpay test mode, with a mock fallback). React + Vite client consumes the API.

**Tech Stack:** Node 20+, Express 4, Mongoose, zod, bcryptjs, jsonwebtoken, helmet, cors, express-rate-limit, Razorpay SDK, Vitest, Supertest, mongodb-memory-server, React 18, Vite, react-router-dom.

**Spec:** `docs/superpowers/specs/2026-10-24-easybook-design.md`

## Global Constraints

- ESM everywhere (`"type": "module"`), Express **4** (not 5), Mongoose models need MongoDB **>= 6.0** (partial index uses `$in`).
- API envelope on every response: `{ success, data, error }`.
- Deposit = `restaurant.depositPerPerson (25) × partySize`, computed on the server only.
- Hold window 10 minutes. Refund cutoff 2 hours before slot. Timezone IST (UTC+05:30, `TZ_OFFSET_MINUTES = 330`).
- Slots live on a fixed grid: `openTime + n × slotMinutes`, last slot must end by `closeTime`.
- Party size: integer 1–20. Slot length 30–180 minutes.
- Files stay under 400 lines. No mutation of inputs. No `console.log`; use `utils/logger.js`.
- No secrets in git. `.env` ignored, `.env.example` committed.
- Commit messages follow `<type>: <description>` (feat, fix, test, docs, chore, refactor) and **end with the trailer** `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` (add as a second `-m`).
- Tests use far-future dates (`2099-06-15`) for bookings that must be in the future, and inject `now` into services for time-dependent rules.
- Project root: `/Users/adhyan/EasyBook`. Server code in `server/`, client code in `client/`. Run server commands from `server/`.

```js
import mongoose from 'mongoose';
import { ZodError } from 'zod';
import { AppError } from '../utils/AppError.js';
import { logger } from '../utils/logger.js';

const HTTP_BAD_REQUEST = 400;
const HTTP_NOT_FOUND = 404;
const HTTP_CONFLICT = 409;
const HTTP_SERVER_ERROR = 500;
const MONGO_DUPLICATE_KEY = 11000;

export function notFoundHandler(_req, _res, next) {
  next(new AppError(HTTP_NOT_FOUND, 'Route not found'));
}

function describe(err) {
  if (err instanceof AppError) return { status: err.status, message: err.message };
  if (err instanceof ZodError) {
    const message = err.issues.map((i) => `${i.path.join('.') || 'input'}: ${i.message}`).join('; ');
    return { status: HTTP_BAD_REQUEST, message };
  }
  if (err instanceof mongoose.Error.CastError) {
    return { status: HTTP_BAD_REQUEST, message: `Invalid ${err.path}` };
  }
  if (err instanceof mongoose.Error.ValidationError) {
    const message = Object.values(err.errors).map((e) => e.message).join('; ');
    return { status: HTTP_BAD_REQUEST, message };
  }
  if (err?.code === MONGO_DUPLICATE_KEY) return { status: HTTP_CONFLICT, message: 'Duplicate value' };
  if (err?.type === 'entity.parse.failed') return { status: HTTP_BAD_REQUEST, message: 'Malformed JSON body' };
  return { status: HTTP_SERVER_ERROR, message: 'Something went wrong' };
}

export function errorHandler(err, req, res, next) {
  if (res.headersSent) return next(err);
  const { status, message } = describe(err);
  if (status >= HTTP_SERVER_ERROR) logger.error('Unhandled error', { path: req.path, err });
  return res.status(status).json({ success: false, data: null, error: message });
}
```

`server/src/services/slots.js`:
```js
import { MS_PER_MINUTE, TZ_OFFSET_MINUTES } from '../constants.js';

const MINUTES_PER_HOUR = 60;
const DATE_PATTERN = /^\d{4}-\d{2}-\d{2}$/;

export const toMinutes = (hhmm) => {
  const [hours, minutes] = hhmm.split(':').map(Number);
  return hours * MINUTES_PER_HOUR + minutes;
};

const pad = (value) => String(value).padStart(2, '0');

export const toHHmm = (total) => `${pad(Math.floor(total / MINUTES_PER_HOUR))}:${pad(total % MINUTES_PER_HOUR)}`;

export function generateSlots(openTime, closeTime, slotMinutes) {
  const close = toMinutes(closeTime);
  const slots = [];
  for (let start = toMinutes(openTime); start + slotMinutes <= close; start += slotMinutes) {
    slots.push(toHHmm(start));
  }
  return slots;
}

export const isOnGrid = (slotStart, { openTime, closeTime, slotMinutes }) =>
  generateSlots(openTime, closeTime, slotMinutes).includes(slotStart);

export function slotInstant(date, slotStart) {
  const [year, month, day] = date.split('-').map(Number);
  const utcMs = Date.UTC(year, month - 1, day, 0, toMinutes(slotStart));
  return new Date(utcMs - TZ_OFFSET_MINUTES * MS_PER_MINUTE);
}

export const localDateString = (now) =>
  new Date(now.getTime() + TZ_OFFSET_MINUTES * MS_PER_MINUTE).toISOString().slice(0, 10);

export function isValidDateString(value) {
  if (typeof value !== 'string' || !DATE_PATTERN.test(value)) return false;
  const parsed = new Date(`${value}T00:00:00Z`);
  return !Number.isNaN(parsed.getTime()) && parsed.toISOString().slice(0, 10) === value;
}
```

```js
import { MS_PER_HOUR, REFUND_CUTOFF_HOURS } from '../constants.js';

export const DEPOSIT_DECISION = Object.freeze({ REFUND: 'refund', FORFEIT: 'forfeit' });

export function refundPolicy({ slotAt, now, cancelledBy, cutoffHours = REFUND_CUTOFF_HOURS }) {
  if (cancelledBy === 'owner') return DEPOSIT_DECISION.REFUND;
  if (cancelledBy === 'no_show') return DEPOSIT_DECISION.FORFEIT;
  if (cancelledBy === 'diner') {
    const msBeforeSlot = slotAt.getTime() - now.getTime();
    return msBeforeSlot >= cutoffHours * MS_PER_HOUR ? DEPOSIT_DECISION.REFUND : DEPOSIT_DECISION.FORFEIT;
  }
  throw new Error(`Unknown cancelledBy: ${cancelledBy}`);
}
```

```js
import { User } from '../models/User.js';
import { AppError } from '../utils/AppError.js';
import { asyncHandler } from '../utils/asyncHandler.js';
import { verifyToken } from '../utils/jwt.js';

const INVALID_TOKEN = 'Invalid or expired token';

export const requireAuth = asyncHandler(async (req, _res, next) => {
  const [scheme, token] = (req.headers.authorization ?? '').split(' ');
  if (scheme !== 'Bearer' || !token) throw new AppError(401, 'Authentication required');

  let payload;
  try {
    payload = verifyToken(token);
  } catch {
    throw new AppError(401, INVALID_TOKEN);
  }

  const user = await User.findById(payload.sub).select('-passwordHash');
  if (!user) throw new AppError(401, INVALID_TOKEN);
  req.user = user;
  next();
});

export const requireRole = (role) => (req, _res, next) =>
  req.user?.role === role ? next() : next(new AppError(403, `${role} access only`));
```

```js
import { asyncHandler } from '../utils/asyncHandler.js';

const toPublicUser = (user) => ({ id: user._id, name: user.name, email: user.email, role: user.role });

export const register = asyncHandler(async (req, res) => {
  const { name, email, password, role } = req.valid.body;
  if (await User.exists({ email })) throw new AppError(409, 'Email already registered');
  const passwordHash = await bcrypt.hash(password, BCRYPT_ROUNDS);

});
```

```js
import { Restaurant } from '../models/Restaurant.js';
import { getOwnedRestaurant } from '../services/ownership.js';
import { hasFutureActiveBookings } from '../services/bookingQueries.js';
import { AppError } from '../utils/AppError.js';
import { asyncHandler } from '../utils/asyncHandler.js';
import { escapeRegex } from '../utils/regex.js';
import { sendOk } from '../utils/respond.js';
import { hasRoomForSlot, SCHEDULE_ERROR } from '../validation/restaurantSchemas.js';

const SCHEDULE_FIELDS = ['openTime', 'closeTime', 'slotMinutes'];
const exactI = (value) => new RegExp(`^${escapeRegex(value)}$`, 'i');

export const createRestaurant = asyncHandler(async (req, res) => {
  const restaurant = await Restaurant.create({ ...req.valid.body, owner: req.user._id });
  sendOk(res, restaurant, 201);
});

export const listRestaurants = asyncHandler(async (req, res) => {
  const { city, cuisine, q, page, limit } = req.valid.query;
  const filter = {
    ...(city && { city: exactI(city) }),
    ...(cuisine && { cuisine: exactI(cuisine) }),
    ...(q && { name: new RegExp(escapeRegex(q), 'i') }),
  };
  const [items, total] = await Promise.all([
    Restaurant.find(filter).sort({ name: 1 }).skip((page - 1) * limit).limit(limit),
    Restaurant.countDocuments(filter),
  ]);
  sendOk(res, { items, page, limit, total });
});

export const myRestaurants = asyncHandler(async (req, res) => {
  sendOk(res, await Restaurant.find({ owner: req.user._id }).sort({ name: 1 }));
});

export const getRestaurant = asyncHandler(async (req, res) => {
  const restaurant = await Restaurant.findById(req.valid.params.id);
  if (!restaurant) throw new AppError(404, 'Restaurant not found');
  sendOk(res, restaurant);
});

export const updateRestaurant = asyncHandler(async (req, res) => {
  const restaurant = await getOwnedRestaurant(req.valid.params.id, req.user._id);
  const changes = req.valid.body;

  if (!hasRoomForSlot({ ...restaurant.toObject(), ...changes })) {
    throw new AppError(400, SCHEDULE_ERROR);
  }

  const touchesSchedule = SCHEDULE_FIELDS.some((field) => field in changes && changes[field] !== restaurant[field]);
  if (touchesSchedule && (await hasFutureActiveBookings({ restaurant: restaurant._id }))) {
    throw new AppError(409, 'Cannot change opening hours or slot length while upcoming bookings exist');
  }

  const updated = await Restaurant.findByIdAndUpdate(restaurant._id, { $set: changes }, { new: true, runValidators: true });
  sendOk(res, updated);
});
```

```js
const MONGO_DUPLICATE_KEY = 11000;
const DUPLICATE_LABEL = 'A table with this label already exists';

async function getOwnedTable(tableId, userId) {
  const table = await Table.findById(tableId);
  if (!table) throw new AppError(404, 'Table not found');
  await getOwnedRestaurant(table.restaurant, userId);
  return table;
}

function rethrowDuplicateLabel(err) {
  if (err?.code === MONGO_DUPLICATE_KEY) throw new AppError(409, DUPLICATE_LABEL);
  throw err;
}

export const listTables = asyncHandler(async (req, res) => {
  const restaurant = await getOwnedRestaurant(req.valid.params.id, req.user._id);

  sendOk(res, table, 201);
});

  const updated = await Table.findByIdAndUpdate(table._id, { $set: req.valid.body }, { new: true, runValidators: true })

});
```

```js
import { BOOKING_STATUS, HOLD_SWEEP_INTERVAL_MS, PAYMENT_STATUS } from '../constants.js';
import { Booking } from '../models/Booking.js';
import { Payment } from '../models/Payment.js';
import { logger } from '../utils/logger.js';

async function expireBookings(bookingIds) {
  await Booking.updateMany(
    { _id: { $in: bookingIds }, status: BOOKING_STATUS.PENDING_PAYMENT },
    { $set: { status: BOOKING_STATUS.EXPIRED }, $unset: { holdExpiresAt: 1 } },
  );
  await Payment.updateMany(
    { booking: { $in: bookingIds }, status: PAYMENT_STATUS.CREATED },
    { $set: { status: PAYMENT_STATUS.FAILED } },
  );
}

export async function expireStaleHolds(filter = {}, now = new Date()) {
  const stale = await Booking.find({
    ...filter,
    status: BOOKING_STATUS.PENDING_PAYMENT,
    holdExpiresAt: { $lt: now },
  })
    .select('_id')
    .lean();
  if (stale.length === 0) return 0;
  await expireBookings(stale.map((booking) => booking._id));
  return stale.length;
}

export async function releaseDinerHolds({ diner, restaurant, date, slotStart }) {
  const own = await Booking.find({ diner, restaurant, date, slotStart, status: BOOKING_STATUS.PENDING_PAYMENT })
    .select('_id')
    .lean();
  if (own.length === 0) return 0;
  await expireBookings(own.map((booking) => booking._id));
  return own.length;
}

export function startHoldExpiryJob(intervalMs = HOLD_SWEEP_INTERVAL_MS) {
  const timer = setInterval(() => {
    expireStaleHolds().catch((err) => logger.error('Hold expiry sweep failed', { err }));
  }, intervalMs);
  timer.unref();
  return () => clearInterval(timer);
}
```

```js
import { ACTIVE_BOOKING_STATUSES, BOOKING_STATUS } from '../constants.js';
import { Booking } from '../models/Booking.js';
import { Restaurant } from '../models/Restaurant.js';
import { Table } from '../models/Table.js';
import { AppError } from '../utils/AppError.js';
import { expireStaleHolds } from './holdExpiry.js';
import { generateSlots, slotInstant } from './slots.js';

const isLiveHold = (booking, now) =>
  booking.status !== BOOKING_STATUS.PENDING_PAYMENT || (booking.holdExpiresAt && booking.holdExpiresAt > now);

const blocksTable = (booking, now) => ACTIVE_BOOKING_STATUSES.includes(booking.status) && isLiveHold(booking, now);

export function computeAvailability({ restaurant, date, tables, bookings, partySize, now }) {
  const fitting = tables.filter((table) => table.isActive && table.seats >= partySize);
  return generateSlots(restaurant.openTime, restaurant.closeTime, restaurant.slotMinutes).map((slotStart) => {
    const taken = new Set(
      bookings.filter((b) => b.slotStart === slotStart && blocksTable(b, now)).map((b) => String(b.table)),
    );
    const isFuture = slotInstant(date, slotStart) > now;
    const hasFreeTable = fitting.some((table) => !taken.has(String(table._id)));
    return { slotStart, isAvailable: isFuture && hasFreeTable };
  });
}

export async function getAvailability({ restaurantId, date, partySize }, now = new Date()) {
  const restaurant = await Restaurant.findById(restaurantId);
  if (!restaurant) throw new AppError(404, 'Restaurant not found');
  await expireStaleHolds({ restaurant: restaurant._id, date }, now);
  const [tables, bookings] = await Promise.all([
    Table.find({ restaurant: restaurant._id }).lean(),
    Booking.find({ restaurant: restaurant._id, date }).lean(),
  ]);
  const slots = computeAvailability({ restaurant, date, tables, bookings, partySize, now });
  return { date, partySize, slots };
}
```

```js
export function createRazorpayGateway() {
```

```js
import { BOOKING_STATUS, HOLD_MINUTES, MS_PER_MINUTE, PAISE_PER_RUPEE } from '../constants.js';
import { getGateway } from '../gateway/index.js';
import { Booking } from '../models/Booking.js';
import { Payment } from '../models/Payment.js';
import { Restaurant } from '../models/Restaurant.js';
import { Table } from '../models/Table.js';
import { AppError } from '../utils/AppError.js';
import { logger } from '../utils/logger.js';
import { expireStaleHolds, releaseDinerHolds } from './holdExpiry.js';
import { isOnGrid, slotInstant } from './slots.js';

const MONGO_DUPLICATE_KEY = 11000;

function assertBookableSlot(restaurant, date, slotStart, now) {
  if (!isOnGrid(slotStart, restaurant)) throw new AppError(422, 'That time is not a bookable slot');
  if (slotInstant(date, slotStart) <= now) throw new AppError(422, 'That slot is in the past');
}

async function holdFirstFreeTable({ tables, restaurant, diner, date, slotStart, partySize, now }) {
  const holdExpiresAt = new Date(now.getTime() + HOLD_MINUTES * MS_PER_MINUTE);
  for (const table of tables) {
    try {
      const booking = await Booking.create({
        restaurant: restaurant._id,
        table: table._id,
        diner: diner._id,
        date,
        slotStart,
        partySize,
        status: BOOKING_STATUS.PENDING_PAYMENT,
        holdExpiresAt,
      });
      return { booking, table };
    } catch (err) {
      if (err?.code !== MONGO_DUPLICATE_KEY) throw err;
    }
  }
  throw new AppError(409, 'That slot was just taken. Please pick another time.');
}

async function openPaymentOrder({ booking, restaurant, partySize }) {
  const depositAmount = restaurant.depositPerPerson * partySize;
  const gateway = getGateway();
  try {
    const order = await gateway.createOrder({
      amountPaise: depositAmount * PAISE_PER_RUPEE,
      receipt: String(booking._id),
    });
    await Payment.create({
      booking: booking._id,
      restaurant: restaurant._id,
      amount: depositAmount,
      gatewayOrderId: order.orderId,
    });
    return { depositAmount, order: { ...order, gateway: gateway.name } };
  } catch (err) {
    await Booking.deleteOne({ _id: booking._id });
    logger.error('Could not open payment order', { bookingId: booking._id, err });
    throw new AppError(502, 'Payment service is unavailable. Please try again.');
  }
}

export async function createBooking({ diner, restaurantId, date, slotStart, partySize }, now = new Date()) {
  const restaurant = await Restaurant.findById(restaurantId);
  if (!restaurant) throw new AppError(404, 'Restaurant not found');
  assertBookableSlot(restaurant, date, slotStart, now);

  await expireStaleHolds({ restaurant: restaurant._id, date }, now);
  await releaseDinerHolds({ diner: diner._id, restaurant: restaurant._id, date, slotStart });

  const tables = await Table.find({
    restaurant: restaurant._id,
    isActive: true,
    seats: { $gte: partySize },
  }).sort({ seats: 1, label: 1 });
  if (tables.length === 0) throw new AppError(422, 'No table can seat a party this large');

  const { booking, table } = await holdFirstFreeTable({ tables, restaurant, diner, date, slotStart, partySize, now });
  const { order, depositAmount } = await openPaymentOrder({ booking, restaurant, partySize });
  return { booking, table: { _id: table._id, label: table.label, seats: table.seats }, order, depositAmount };
}
```

```js
import { BOOKING_STATUS, PAISE_PER_RUPEE, PAYMENT_STATUS } from '../constants.js';
import { getGateway } from '../gateway/index.js';
import { Booking } from '../models/Booking.js';
import { Payment } from '../models/Payment.js';
import { AppError } from '../utils/AppError.js';
import { logger } from '../utils/logger.js';
import { DEPOSIT_DECISION } from './refundPolicy.js';

const MONGO_DUPLICATE_KEY = 11000;
const REFUND_FAILED_MESSAGE = 'The refund could not be processed automatically. Please contact the restaurant.';

export async function settleDeposit(bookingId, decision) {
  const payment = await Payment.findOne({ booking: bookingId, status: PAYMENT_STATUS.PAID });
  if (!payment) return { status: 'none', amount: 0 };

  const transition = (status) => Payment.updateOne({ _id: payment._id, status: PAYMENT_STATUS.PAID }, { $set: { status } });

  if (decision === DEPOSIT_DECISION.FORFEIT) {
    await transition(PAYMENT_STATUS.FORFEITED);
    return { status: PAYMENT_STATUS.FORFEITED, amount: payment.amount };
  }

  try {
    await getGateway().refund({
      paymentId: payment.gatewayPaymentId,
      amountPaise: payment.amount * PAISE_PER_RUPEE,
    });
  } catch (err) {
    await transition(PAYMENT_STATUS.REFUND_FAILED);
    logger.error('Gateway refund failed', { bookingId, err });
    throw new AppError(502, REFUND_FAILED_MESSAGE);
  }
  await transition(PAYMENT_STATUS.REFUNDED);
  return { status: PAYMENT_STATUS.REFUNDED, amount: payment.amount };
}

async function confirmBooking(bookingId) {
  try {
    return await Booking.findOneAndUpdate(
      { _id: bookingId, status: { $in: [BOOKING_STATUS.PENDING_PAYMENT, BOOKING_STATUS.EXPIRED] } },
      { $set: { status: BOOKING_STATUS.CONFIRMED }, $unset: { holdExpiresAt: 1 } },
      { new: true },
    );
  } catch (err) {
    if (err?.code === MONGO_DUPLICATE_KEY) return null; // slot was rebooked while the hold was expired
    throw err;
  }
}

async function refundUnconfirmable(bookingId) {
  try {
    await settleDeposit(bookingId, DEPOSIT_DECISION.REFUND);
  } catch (err) {
    if (err instanceof AppError && err.status === 502) {
      return { outcome: 'refund_failed', booking: await Booking.findById(bookingId) };
    }
    throw err;
  }
  return { outcome: 'refunded', booking: await Booking.findById(bookingId) };
}

export async function confirmPayment({ orderId, paymentId, paidAmountPaise }) {
  const payment = await Payment.findOne({ gatewayOrderId: orderId });
  if (!payment) throw new AppError(404, 'Unknown payment order');

  if (paidAmountPaise !== undefined && paidAmountPaise !== payment.amount * PAISE_PER_RUPEE) {
    logger.error('Payment amount mismatch', { orderId, expected: payment.amount * PAISE_PER_RUPEE, paidAmountPaise });
    throw new AppError(400, 'Payment amount mismatch');
  }

  // Only one caller can claim the payment, so verify + webhook cannot double-process.
  const claimed = await Payment.findOneAndUpdate(
    { _id: payment._id, status: { $in: [PAYMENT_STATUS.CREATED, PAYMENT_STATUS.FAILED] } },
    { $set: { status: PAYMENT_STATUS.PAID, gatewayPaymentId: paymentId } },
    { new: true },
  );
  if (!claimed) return { outcome: 'already_processed', booking: await Booking.findById(payment.booking) };

  const booking = await confirmBooking(payment.booking);
  if (booking) return { outcome: 'confirmed', booking };
  return refundUnconfirmable(payment.booking);
}
```

```js
function respondWithOutcome(res, { outcome, booking }) {
  if (outcome === 'refunded') {
    throw new AppError(409, 'Your hold expired and the slot was taken. Your payment has been refunded.');
  }
  if (outcome === 'refund_failed') {
    throw new AppError(502, 'Your hold expired and the slot was taken, but the refund failed. Contact the restaurant.');
  }

}

export const verify = asyncHandler(async (req, res) => {
  const { orderId, paymentId, signature } = req.valid.body;
  const payment = await Payment.findOne({ gatewayOrderId: orderId }).populate('booking', 'diner');
  if (!payment?.booking) throw new AppError(404, 'Unknown payment order');
  if (!payment.booking.diner.equals(req.user._id)) throw new AppError(403, 'This is not your booking');
  if (!getGateway().verifyPaymentSignature({ orderId, paymentId, signature })) {
    throw new AppError(400, 'Invalid payment signature');
  }
  respondWithOutcome(res, await confirmPayment({ orderId, paymentId }));
});

function parseWebhookEvent(rawBody) {
  try {
    return JSON.parse(rawBody.toString('utf8'));
  } catch {
    throw new AppError(400, 'Malformed webhook body');
  }
}

export const webhook = asyncHandler(async (req, res) => {
  const signature = req.get('x-razorpay-signature');
  if (!Buffer.isBuffer(req.body) || !getGateway().verifyWebhookSignature(req.body, signature)) {
    throw new AppError(400, 'Invalid webhook signature');
  }
  const event = parseWebhookEvent(req.body);
  if (event.event !== CAPTURED_EVENT) return sendOk(res, { ignored: true });

  const entity = event.payload?.payment?.entity;
  if (!entity?.id || !entity?.order_id || !Number.isInteger(entity?.amount)) {
    throw new AppError(400, 'Malformed webhook payload');
  }
  const result = await confirmPayment({
    orderId: entity.order_id,
    paymentId: entity.id,
    paidAmountPaise: entity.amount,
  });
  return sendOk(res, { outcome: result.outcome }); // always 200 so the gateway stops retrying
});
```

```js
async function moveBooking(booking, nextStatus) {

    { _id: booking._id, status: booking.status },

export async function cancelBookingAsDiner({ bookingId, userId }, now = new Date()) {
  const booking = await loadBooking(bookingId);
  if (!booking.diner.equals(userId)) throw new AppError(403, 'This is not your booking');
  assertTransition(booking.status, BOOKING_STATUS.CANCELLED);

  const slotAt = slotInstant(booking.date, booking.slotStart);
  if (slotAt <= now) throw new AppError(422, 'This booking has already started');

  const updated = await moveBooking(booking, BOOKING_STATUS.CANCELLED);
  const deposit = await settleDeposit(booking._id, refundPolicy({ slotAt, now, cancelledBy: 'diner' }));
  return { booking: updated, deposit };
```

```js
import { PAYMENT_STATUS } from '../constants.js';

const EMPTY = Object.freeze({ pendingAdjustment: 0, adjusted: 0, forfeited: 0, refunded: 0, refundFailed: 0 });

function bucketOf({ status, adjustedAt }) {
  if (status === PAYMENT_STATUS.PAID) return adjustedAt ? 'adjusted' : 'pendingAdjustment';
  if (status === PAYMENT_STATUS.FORFEITED) return 'forfeited';
  if (status === PAYMENT_STATUS.REFUNDED) return 'refunded';
  if (status === PAYMENT_STATUS.REFUND_FAILED) return 'refundFailed';
  return null;
}

export function summarizeDeposits(payments) {
  return payments.reduce((totals, payment) => {
    const bucket = bucketOf(payment);
    return bucket ? { ...totals, [bucket]: totals[bucket] + payment.amount } : totals;
  }, { ...EMPTY });
}
```

```js
const API_URL = import.meta.env.VITE_API_URL ?? 'http://localhost:5000/api';
const NETWORK_ERROR = 'Cannot reach the server. Check your connection and try again.';

export class ApiError extends Error {
  constructor(status, message) {
    super(message);
    this.name = 'ApiError';
    this.status = status;
  }
}

export async function request(path, { method = 'GET', body, token } = {}) {
  const headers = {
    ...(body ? { 'Content-Type': 'application/json' } : {}),
    ...(token ? { Authorization: `Bearer ${token}` } : {}),
  };

  let response;
  try {
    response = await fetch(`${API_URL}${path}`, {
      method,
      headers,
      body: body ? JSON.stringify(body) : undefined,
    });
  } catch {
    throw new ApiError(0, NETWORK_ERROR);
  }

  const payload = await response.json().catch(() => null);
  if (!response.ok || !payload?.success) {
    throw new ApiError(response.status, payload?.error ?? 'Request failed');
  }
  return payload.data;
}
```

```jsx
import { createContext, useCallback, useContext, useEffect, useMemo, useState } from 'react';
import { request } from '../api/http.js';

const TOKEN_KEY = 'easybook.token';
const AuthContext = createContext(null);

function readToken() {
  try {
    return localStorage.getItem(TOKEN_KEY);
  } catch {
    return null;
  }
}

function writeToken(token) {
  try {
    if (token) localStorage.setItem(TOKEN_KEY, token);
    else localStorage.removeItem(TOKEN_KEY);
  } catch {
    // Storage can be blocked (private mode); the session just won't persist.
  }
}

export function AuthProvider({ children }) {
  const [token, setToken] = useState(readToken);
  const [user, setUser] = useState(null);
  const [ready, setReady] = useState(() => !readToken());

  useEffect(() => {
    if (!token) {
      setUser(null);
      setReady(true);
      return;
    }
    request('/auth/me', { token })
      .then((data) => setUser(data.user))
      .catch(() => {
        writeToken(null);
        setToken(null);
      })
      .finally(() => setReady(true));
  }, [token]);

  const establish = useCallback((data) => {
    writeToken(data.token);
    setUser(data.user);
    setToken(data.token);
    return data.user;
  }, []);

  const login = useCallback(
    async (email, password) => establish(await request('/auth/login', { method: 'POST', body: { email, password } })),
    [establish],
  );
  const register = useCallback(
    async (fields) => establish(await request('/auth/register', { method: 'POST', body: fields })),
    [establish],
  );
  const logout = useCallback(() => {
    writeToken(null);
    setUser(null);
    setToken(null);
  }, []);
  const call = useCallback((path, options = {}) => request(path, { ...options, token }), [token]);

  const value = useMemo(
    () => ({ user, token, ready, login, register, logout, call }),
    [user, token, ready, login, register, logout, call],
  );
  return <AuthContext.Provider value={value}>{children}</AuthContext.Provider>;
}

export function useAuth() {
  const context = useContext(AuthContext);
  if (!context) throw new Error('useAuth must be used inside AuthProvider');
  return context;
}
```

```js
import { useCallback, useEffect, useRef, useState } from 'react';

export function useLoad(loader, deps) {
  const [state, setState] = useState({ data: null, error: null, loading: true });
  const [version, setVersion] = useState(0);
  const loaderRef = useRef(loader);
  loaderRef.current = loader;

  useEffect(() => {
    let isCurrent = true;
    setState((previous) => ({ ...previous, loading: true, error: null }));
    loaderRef
      .current()
      .then((data) => isCurrent && setState({ data, error: null, loading: false }))
      .catch((error) => isCurrent && setState({ data: null, error, loading: false }));
    return () => {
      isCurrent = false;
    };
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [...deps, version]);

  const reload = useCallback(() => setVersion((v) => v + 1), []);
  return { ...state, reload };
}
```

```js
import { useEffect, useState } from 'react';

const TICK_MS = 1000;

const secondsUntil = (iso) => (iso ? Math.max(0, Math.ceil((new Date(iso).getTime() - Date.now()) / TICK_MS)) : 0);

export function useCountdown(deadlineIso) {
  const [seconds, setSeconds] = useState(() => secondsUntil(deadlineIso));
  useEffect(() => {
    setSeconds(secondsUntil(deadlineIso));
    if (!deadlineIso) return undefined;
    const timer = setInterval(() => setSeconds(secondsUntil(deadlineIso)), TICK_MS);
    return () => clearInterval(timer);
  }, [deadlineIso]);
  return seconds;
}
```

```js
const RAZORPAY_SCRIPT = 'https://checkout.razorpay.com/v1/checkout.js';

function loadRazorpay() {
  if (window.Razorpay) return Promise.resolve();
  return new Promise((resolve, reject) => {
    const script = document.createElement('script');
    script.src = RAZORPAY_SCRIPT;
    script.onload = resolve;
    script.onerror = () => reject(new Error('Could not load the payment window. Check your connection.'));
    document.body.appendChild(script);
  });
}

export async function collectPayment({ order, bookingId, user, call }) {
  if (order.gateway === 'mock') {
    return call('/payments/mock-pay', { method: 'POST', body: { bookingId } });
  }
  await loadRazorpay();
  return new Promise((resolve, reject) => {
    const checkout = new window.Razorpay({
      key: order.keyId,
      amount: order.amount,
      currency: order.currency,
      order_id: order.orderId,
      name: 'EasyBook',
      description: 'Table booking deposit',
      prefill: { name: user.name, email: user.email },
      handler: (response) =>
        resolve({
          orderId: response.razorpay_order_id,
          paymentId: response.razorpay_payment_id,
          signature: response.razorpay_signature,
        }),
      modal: { ondismiss: () => reject(new Error('Payment was cancelled. Your table is held until the timer ends.')) },
    });
    checkout.on('payment.failed', (response) => reject(new Error(response.error?.description ?? 'Payment failed')));
    checkout.open();
  });
}
```

```jsx
const SLOT_TAKEN = 409;

function Confirmation({ booking, restaurant }) {
  return (
    <div className="card">
      <p className="banner banner-ok">Booking confirmed. A table is reserved for you.</p>
      <p><strong>{restaurant.name}</strong></p>
      <p>{formatDate(booking.date)} at {booking.slotStart} for {booking.partySize}</p>

export default function RestaurantDetail() {
  const { id } = useParams();
  const { user, call } = useAuth();
  const restaurant = useLoad(() => call(`/restaurants/${id}`), [id]);
  const [date, setDate] = useState(todayLocal());
  const [partySize, setPartySize] = useState(2);
  const [slots, setSlots] = useState(null);
  const [selected, setSelected] = useState(null);
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState(null);
  const [held, setHeld] = useState(null);
  const [confirmed, setConfirmed] = useState(null);
  const secondsLeft = useCountdown(held?.booking.holdExpiresAt);

  const checkAvailability = useCallback(async () => {
    setBusy(true);
    setError(null);
    setSelected(null);
    try {
      const data = await call(`/restaurants/${id}/availability?date=${date}&partySize=${partySize}`);
      setSlots(data.slots);
    } catch (err) {
      setError(err);
    } finally {
      setBusy(false);
    }
  }, [call, id, date, partySize]);

  const bookAndPay = async () => {
    setBusy(true);
    setError(null);
    try {
      const hold = await call('/bookings', {
        method: 'POST',
        body: { restaurantId: id, date, slotStart: selected, partySize: Number(partySize) },
      });
      setHeld(hold);
      const payment = await collectPayment({ order: hold.order, bookingId: hold.booking._id, user, call });
      const result = await call('/payments/verify', { method: 'POST', body: payment });
      setConfirmed(result.booking);
    } catch (err) {
      setError(err);
      if (err.status === SLOT_TAKEN) checkAvailability();
    } finally {
      setHeld(null);
      setBusy(false);
    }
  };

  if (restaurant.loading) return <Spinner />;
  if (restaurant.error) return <ErrorBanner error={restaurant.error} />;
  const place = restaurant.data;
  const deposit = place.depositPerPerson * Number(partySize || 0);
  const isDiner = user?.role === 'diner';

  return (
    <>
      <h1>{place.name}</h1>
      <p className="muted">{place.cuisine} · {place.address}, {place.city} · {place.openTime} – {place.closeTime}</p>
      {place.description && <p>{place.description}</p>}

      {confirmed ? (
        <Confirmation booking={confirmed} restaurant={place} />
      ) : !isDiner ? (
        <p className="banner banner-warn">
          {user ? 'Only diner accounts can book tables.' : <><Link to="/login">Log in</Link> as a diner to book a table.</>}
        </p>
      ) : (
        <section className="card">
          <h2>Book a table</h2>
          <div className="row">
            <label>Date<input type="date" min={todayLocal()} value={date} onChange={(e) => setDate(e.target.value)} /></label>
            <label>Guests
              <input type="number" min={1} max={MAX_PARTY_SIZE} value={partySize} onChange={(e) => setPartySize(e.target.value)} />
            </label>
            <button type="button" disabled={busy || !date || !(partySize >= 1)} onClick={checkAvailability}>
              Check availability
            </button>
          </div>
          <ErrorBanner error={error} />
          {slots && <SlotPicker slots={slots} selected={selected} onSelect={setSelected} />}
          {selected && (
            <div className="card">
              <p>
                {formatDate(date)} at <strong>{selected}</strong> for {partySize}. Deposit: <strong>{rupees(deposit)}</strong>{' '}
                ({rupees(place.depositPerPerson)} per person), adjusted against your bill. Free cancellation up to 2 hours before.
              </p>
              {held && (
                <p className="banner banner-warn" role="status">
                  {secondsLeft > 0 ? `Table held for ${clock(secondsLeft)}. Complete payment to confirm.` : 'Hold expired. Please try again.'}
                </p>
              )}
              <button type="button" disabled={busy} onClick={bookAndPay}>
                {busy ? 'Processing…' : `Pay ${rupees(deposit)} and confirm`}
              </button>
            </div>
          )}
        </section>
      )}
    </>

}
```

```jsx
import { useState } from 'react';
import { Link } from 'react-router-dom';
import { EmptyState, ErrorBanner, Spinner } from '../components/Feedback.jsx';
import { useAuth } from '../context/AuthContext.jsx';
import { useLoad } from '../hooks/useLoad.js';
import { DEPOSIT_LABEL, formatDate, rupees, STATUS_LABEL } from '../lib/format.js';

const IST_OFFSET = '+05:30';
const MS_PER_HOUR = 3_600_000;
const REFUND_CUTOFF_HOURS = 2;

const hoursUntil = (booking) =>
  (new Date(`${booking.date}T${booking.slotStart}:00${IST_OFFSET}`).getTime() - Date.now()) / MS_PER_HOUR;

function cancelWarning(booking) {
  const refundable = hoursUntil(booking) >= REFUND_CUTOFF_HOURS;
  return refundable
    ? `Cancel this booking? Your ${rupees(booking.deposit.amount)} deposit will be refunded.`
    : `Cancel this booking? It starts in under ${REFUND_CUTOFF_HOURS} hours, so your ${rupees(booking.deposit.amount)} deposit will NOT be refunded.`;
}

export default function MyBookings() {
  const { call } = useAuth();
  const { data, error, loading, reload } = useLoad(() => call('/bookings/mine'), []);
  const [busyId, setBusyId] = useState(null);
  const [actionError, setActionError] = useState(null);
  const [notice, setNotice] = useState(null);

  const cancel = async (booking) => {
    if (!window.confirm(cancelWarning(booking))) return;
    setBusyId(booking._id);
    setActionError(null);
    setNotice(null);
    try {
      const result = await call(`/bookings/${booking._id}/cancel`, { method: 'PATCH' });
      setNotice(`Booking cancelled. Deposit ${DEPOSIT_LABEL[result.deposit.status]?.toLowerCase() ?? 'settled'}.`);
    } catch (err) {
      setActionError(err);
    } finally {
      setBusyId(null);
      reload();
    }
  };

  return (
    <>
      <h1>My bookings</h1>
      <ErrorBanner error={error ?? actionError} />
      {notice && <p className="banner banner-ok" role="status">{notice}</p>}
      {loading && <Spinner />}
      {data?.length === 0 && <EmptyState>No bookings yet. <Link to="/">Find a table</Link></EmptyState>}
      {data?.map((booking) => (
        <div className="card" key={booking._id}>
          <div className="row">
            <h2>{booking.restaurant?.name ?? 'Restaurant'}</h2>
            <span className={`badge ${booking.status}`}>{STATUS_LABEL[booking.status]}</span>
          </div>
          <p>{formatDate(booking.date)} at {booking.slotStart} · {booking.partySize} guests · Table {booking.table?.label ?? 'n/a'}</p>
          {booking.deposit && (
            <p className="muted">
              Deposit {rupees(booking.deposit.amount)}:{' '}
              <span className={`badge ${booking.deposit.status}`}>{DEPOSIT_LABEL[booking.deposit.status]}</span>
              {booking.deposit.adjustedAt && ' · adjusted against your bill'}
            </p>
          )}
          {booking.status === 'confirmed' && hoursUntil(booking) > 0 && (
            <button type="button" className="danger" disabled={busyId === booking._id} onClick={() => cancel(booking)}>
              {busyId === booking._id ? 'Cancelling…' : 'Cancel booking'}
            </button>
          )}
        </div>
      ))}
    </>
  );
}
```

```jsx
import { useState } from 'react';
import { Link, useParams } from 'react-router-dom';
import { EmptyState, ErrorBanner, Spinner } from '../components/Feedback.jsx';
import { useAuth } from '../context/AuthContext.jsx';
import { useLoad } from '../hooks/useLoad.js';

export default function ManageTables() {
  const { id } = useParams();
  const { call } = useAuth();
  const { data, error, loading, reload } = useLoad(() => call(`/restaurants/${id}/tables`), [id]);
  const [form, setForm] = useState({ label: '', seats: 2 });
  const [actionError, setActionError] = useState(null);
  const [busy, setBusy] = useState(false);

  const run = async (action) => {
    setBusy(true);
    setActionError(null);
    try {
      await action();
      reload();
    } catch (err) {
      setActionError(err);
    } finally {
      setBusy(false);
    }
  };

  const addTable = (event) => {
    event.preventDefault();
    return run(async () => {
      await call(`/restaurants/${id}/tables`, { method: 'POST', body: { label: form.label, seats: Number(form.seats) } });
      setForm({ label: '', seats: 2 });
    });
  };

    run(() => call(`/tables/${table._id}`, { method: 'PATCH', body: { isActive: !table.isActive } }));

    if (!window.confirm(`Delete table ${table.label}?`)) return undefined;
    return run(() => call(`/tables/${table._id}`, { method: 'DELETE' }));
  };

  return (
    <>
      <p><Link to="/owner">← My restaurants</Link></p>
```

````markdown
# EasyBook

Table reservations with a refundable deposit, built for restaurants that still take bookings over phone and WhatsApp.

**Live app:** https://[client-url]  ·  **API:** https://[api-url]/api/health  ·  **Demo video:** [link]

**Demo logins** (test data): owner `owner@demo.com` / `password123`, diner `diner@demo.com` / `password123`

## Problem Statement

Small restaurants take reservations by phone and chat. That causes double-bookings, no-shows that cost them real revenue, and no single view of the day's reservations.

## Target Users

- **Diners** who want a guaranteed table at a specific time without calling.
- **Restaurant owners** who want conflict-free bookings, fewer no-shows, and a daily reservation list.

## Solution

Owners publish their tables and opening hours. Diners pick a date, party size and time slot. The server assigns the smallest free table that fits and holds it for 10 minutes while the diner pays a ₹25-per-person deposit. The deposit is refunded for cancellations made 2+ hours ahead, kept by the restaurant on no-shows and late cancellations, and adjusted against the bill when the guests are seated.

## Key Features

1. **Owner setup:** create restaurants, set hours and slot length, manage tables (enable, disable, delete).
2. **Search and book:** filter restaurants, see live availability for a party size, book with automatic table assignment.
3. **Deposit payment:** 10-minute table hold with countdown, signature-verified payment (verify + webhook), automatic expiry and automatic refund if a late payment finds the slot taken.
4. **Lifecycle:** diner cancellation with refund policy, owner marks seated / completed / no-show / cancelled, owner adjusts the deposit at billing, deposits ledger.

## Tech Stack

React 18 + Vite · Node 20 + Express 4 · MongoDB (Atlas) + Mongoose · JWT + bcrypt · zod · Razorpay (test mode, with a mock gateway fallback) · Vitest + Supertest.

## Architecture

```
React client ──HTTPS──> Express API ──> MongoDB
                         │   ├─ controllers (thin HTTP layer)
                         │   ├─ services    (pure rules: slots, availability, refund policy, state machine)
                         │   └─ gateway     (Razorpay / mock adapter)
                         └─ hold-expiry job (every 60s, plus lazy expiry on reads)
```

- **No double-booking:** slots sit on a fixed grid, so two bookings conflict only when `(table, date, slotStart)` match. A MongoDB **partial unique index** over active statuses enforces this atomically. When two diners race, one insert fails with a duplicate key error, the API tries the next-smallest table and finally returns 409.
- **Deposit safety:** amount computed on the server (`₹25 × guests`), payment claimed atomically so verify and webhook cannot double-process, late payments on a taken slot are refunded automatically.
- **Booking state machine:** `pending_payment → confirmed → seated → completed`, plus `expired`, `cancelled`, `no_show`. Illegal transitions return 409.
- **Deliberate simplification:** fixed slot length per restaurant (no custom stay durations).
- **Payout model:** the platform collects deposits (Razorpay test mode) and a ledger records what each restaurant is owed until the owner adjusts it at billing. Real split payouts (Razorpay Route + KYC) are out of scope.

## Local Setup

Requires Node 20+ and a MongoDB (local or Atlas).

cd server && cp .env.example .env     # fill in MONGO_URI and JWT_SECRET

```
````
